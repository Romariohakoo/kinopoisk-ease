# Kinopoisk Ease

Расширение для Chrome и других Chromium-браузеров. На странице фильма или сериала на Кинопоиске добавляет кнопку «Смотреть на …», которая ведёт на выбранное зеркало, и компактную плавающую плашку для тех, кто уже прокрутил страницу.

- **Кнопка на странице** встаёт рядом со штатной «Буду смотреть» и подстраивается под светлый или тёмный фон сайта.
- **Плавающая плашка** появляется, когда кнопка ушла с экрана. В компактном виде показывает мини-постер, название, рейтинг, год и длительность или число сезонов. Стрелка раскрывает подробности: тип, описание, «Скрыть на этом тайтле». Выбор вида запоминается.
- **Зеркала:** можно задать список и проверить доступность. Если основное не отвечает, кнопки ведут на следующее.
- **Shift+W** — смотреть с клавиатуры. Не срабатывает, пока вы печатаете, например в поиске сайта.
- **Настройки** по иконке расширения: кнопка на странице, режим плашки (автоматически, всегда, никогда), позиция на экране, тема (как у сайта, тёмная, светлая), новая вкладка, горячая клавиша, скрытые тайтлы, включение и выключение на сайте. Изменения применяются в открытых вкладках сразу и синхронизируются через `chrome.storage.sync`.
- **Типы тайтлов:** фильмы, сериалы, мини-сериалы, аниме, мультфильмы, ТВ-шоу и документальные (`/film/…` и `/series/…`) на доменах `kinopoisk.ru`, `.com`, `.kz`, `.by`. Переходы внутри сайта без перезагрузки обрабатываются, данные предыдущего фильма не показываются.
- **Оформление:** плашка живёт в Shadow DOM и не конфликтует со стилями сайта. Акцентный цвет берётся из постера, если сайт картинок разрешает его прочитать. На телефоне плашка превращается в нижнюю панель. Учитывается `prefers-reduced-motion`, кнопки доступны с клавиатуры и для скринридеров.

## Установка

1. Скачайте репозиторий (или архив из `npm run build`, см. ниже).
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку **`extension/`**.

> Раньше расширение лежало в корне репозитория. Если оно было загружено оттуда, удалите его и загрузите заново из `extension/`.

## Разработка

Нужен Node.js 18+.

```bash
npm install
npx playwright install chromium   # один раз, браузер для e2e-тестов

npm run lint          # ESLint
npm run format        # Prettier (npm run format:check — только проверка)
npm run test:unit     # unit-тесты чистых функций (node:test)
npm run test:e2e      # e2e: Chromium с загруженным расширением
npm test              # всё вместе
npm run build         # dist/kinopoisk-ease-<версия>.zip
npm run icons         # перерисовать иконки из SVG
```

Для e2e-тестов живой Кинопоиск не нужен. Playwright перехватывает запросы к `*.kinopoisk.*` и отдаёт страницы из `tests/e2e/fixtures/`, которые повторяют разметку сайта: CSS-модули `styles_xxx__hash`, `film-poster`, `data-tid`, таблица «О фильме», кнопки «Смотреть»/«Буду смотреть», og-мета, JSON-LD и SPA-переходы через `history.pushState` с задержкой загрузки контента. Если Кинопоиск поменяет вёрстку, обновите фикстуры по живой странице. Для отладки с видимым окном браузера: `HEADED=1 npm run test:e2e`.

### Структура

```
extension/            ← то, что загружается в браузер
  manifest.json
  src/lib.js          чистые функции: адрес, заголовок, рейтинг, длительность, настройки, цвет постера
  src/extract.js      чтение данных со страницы с цепочкой запасных селекторов
  src/ui.js           общие кирпичики интерфейса: DOM без innerHTML, иконки, шрифты, тема
  src/inline.js/.css  кнопка «Смотреть на …» внутри страницы
  src/widget.js/.css  плавающая плашка (Shadow DOM)
  src/content.js      точка входа: навигация, ожидание данных, видимость плашки, Shift+W
  src/background.js   service worker: проверка зеркал, открытие настроек
  options/            настройки (попап по иконке и отдельная страница)
  fonts/, icons/
tests/unit/           unit-тесты lib.js
tests/e2e/            Playwright: сценарии и фикстуры страниц Кинопоиска
scripts/              сборка zip и генерация иконок
```
